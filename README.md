BMI Calculator 🧮

A simple BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript. It calculates BMI based on height (cm) and weight (kg) and displays the result instantly.

🚀 Features
Enter height in cm
Enter weight in kg
Instant BMI calculation
Clean and simple UI

🛠️ Technologies Used
HTML5
CSS3
JavaScript

📂 How to Run
Clone the repository.
Open index.html in your browser.
Enter your height and weight.
Click Calculate to see your BMI.
